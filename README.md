# 부자재 재고 확인 및 발주 자동화 프롬프트

```
[도메인 맥락]
나는 제조업 생산 도메인 3년 차이고, 프로젝트마다 반복하는 재고 확인과 부족 부자재 발주 작업을 자동화/정리하고 싶습니다.

[네 동작 분석]
1. 분해: 제품별 필요 부자재 종류, 부자재별 현재 재고수량, 부자재별 필요수량, 부자재별 발주 단위(800개, 1,500개 등), 부자재별 리드타임, 프로젝트별 생산일정으로 나눔
2. 패턴: 매번 확인하는 3가지 — 부자재 종류, 현재 재고, 발주 단위
   + 여러 프로젝트가 같은 부자재를 함께 쓰는 경우가 있음
3. 추상화: "무엇을, 언제, 몇 개 발주하는가" 한 줄로 부자재별 요약 → 안전재고 없이 재고는 최소로, 발주 횟수도 최소로, 생산일정에 맞춰 제때 입고
4. 알고리즘: 프로젝트별 생산수량·생산시작일 입력
   → 제품별 필요 부자재 확인
   → 같은 부자재를 쓰는 프로젝트끼리 묶고, 생산시작일이 빠른 프로젝트부터 현재 재고를 배정
   → 부족수량 = (생산수량 × 제품당 소요량) − 배정된 재고
   → 발주수량 = 부족수량을 발주 단위로 올림 (예: 부족 1,200개, 단위 800개 → 1,600개)
   → 남는 수량(올림분)은 같은 부자재를 쓰는 다음 프로젝트에 먼저 배정
   → 발주일 = 생산시작일 − 리드타임 − 여유일 3일 (여유일은 2~3일 범위에서 보수적으로 3일 적용)
   → 발주일이 가까운 같은 부자재 발주는 하나로 합쳐 발주 횟수 줄이기
   → 부자재별 발주 체크리스트 출력

[출력 요구]
생산일정 기준으로 부자재별 [사용 프로젝트 / 발주일 / 발주수량 / 예상 입고일 / 발주 후 잔여재고 / 발주 완료 체크]가 들어간 한 장짜리 체크리스트 형식으로, 한국어로.
발주일이 이미 지났거나 임박한 부자재는 맨 위에 표시.

[검증 기준]
생산 담당자인 내가 "한눈에 생산일정과 발주일정을 볼 수 있다"고 평가할 것.
실제로는 모든 부자재가 생산시작일 전에 정확한 수량으로 입고되었는지로 판단한다.
```
